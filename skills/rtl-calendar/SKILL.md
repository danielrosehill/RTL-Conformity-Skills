# RTL in calendar events

Apply the rules in the rtl-basics skill. This skill adds what is specific to
calendars.

Calendar fields are mostly plain text: the title, the location and, on many
clients, the description. You cannot set a direction on them. Phones, the web and
desktop apps each guess direction from the first strong character, and
notification previews guess again.

## Title

- **Start the title with Hebrew.** `רופא ילדים – Dr. Cohen`, not `Dr. Cohen – רופא ילדים`.
  The first strong character decides the direction in most clients.
- If the title has to start with Latin or a number (a time, a flight number),
  prefix it with U+200F, the actual invisible character.
- Keep identifiers (flight numbers, booking references) out of the title. Put them
  on a line of their own in the description.

## Description

- Google Calendar's API says the description "can contain HTML", but which tags
  and attributes survive differs between clients. Whether `dir` is honoured is
  untested here. Write it so it works either way: short lines, each starting with
  U+200F, and plain `<br>` or newlines between them.
- One fact per line: address, phone, reference number, what to bring. A number
  alone on a line cannot be reordered by the text around it.
- Links go on a line of their own, after the Hebrew text.

## Location

Enter the address the way the map service expects it, in Hebrew or English but
not mixed: `רחוב יפו 97, ירושלים` or `97 Jaffa St, Jerusalem`. A mixed-script address
is more likely to fail to geocode than to display wrongly.

## Time and date

- Always set the time zone explicitly to `Asia/Jerusalem` for events in Israel.
  Don't rely on the calendar's default: a calendar created abroad, or a travelling
  device, shifts the event.
- When reading a date from the user or a document, Israeli dates are day-first:
  `5/11` is 5 November.
- Shabbat and Jewish holidays begin at sundown the evening before. An all-day
  event on the holiday's date does not show that, so add a timed event for the
  start when it matters. "Erev chag" (the eve) is the preceding day itself. In Israel a
  festival has one day of Yom Tov, not the two kept abroad.
- Friday afternoon and Saturday are generally not available for ordinary
  appointments. Flag an event placed during Shabbat unless the user asked for it.

## Invitations to others

Invitation emails generated by the calendar use the event text as-is. The title
rule above matters twice as much there. If you are also sending a separate email
about the event, follow the rtl-email skill.
